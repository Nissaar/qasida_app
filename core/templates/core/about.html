Where the texts come from

Almost nothing here was written for this site. The texts are collected from sites that already publish them, and from scanned pages of books and pamphlets, and each work records where it was taken from. {% if sources %}The library currently reads from {% for source in sources %}{{ source.name }}{% if not forloop.last %}, {% endif %}{% endfor %}.{% endif %}

If something here is yours and you would rather it were not, write and it will be taken down. That is not a formality — see the contact page.

How much to trust a text

A good deal of this was read off images by machine, and machines misread Arabic script in ways a reader would not. So each work says what kind of text it carries: extracted cleanly, reconstructed, or unreliable enough that the scan is the thing to read. Nothing goes on the site until a person has looked at it, and a translation produced by machine is labelled as one.

Where a work is held as scanned pages, the scan is not decoration. It is what the text was read off, and the only record worth anything where the reading is doubtful.

Reading it offline

The site installs as an app and keeps what you have already opened, so a gathering in a basement with no signal is not a reason to be without the text. Any work can also be downloaded as a PDF, with or without its transliteration, translation and scans.
